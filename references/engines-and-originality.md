# 人物发动机、故事发动机与原创化

## 人物发动机

从核验资料中提炼抽象机制，不复述人物传记：核心欲望、核心恐惧、性格矛盾、关系模式、社会位置和命运逻辑。

把以上内容压缩成一句内部命题：“一个因为……而渴望……、又害怕……的人，在关系中总会……，最终容易……。”不要把这句话直接写进小说。

## 故事发动机

从作品 B 的指定故事或场景提炼：人物关系及权力差、表层目标与深层冲突、各方信息差、压力升级、关键转折、最终选择及代价。

把它抽象成因果骨架，不沿用原作事件表。例如：“弱势者依赖强势者 → 隐瞒制造暂时稳定 → 第三方获得证据 → 公开与沉默都要付出代价。”

## 融合方法

1. 先设计一个能触发人物发动机的全新现代困境。
2. 再用故事发动机安排压力和选择，而非套用原作场景。
3. 让人物性格改变故事骨架的走向，避免换名复述。
4. 为主角、对手和关键配角分别设置合理诉求，不把任何人只当工具。
5. 让结局由主角的核心矛盾与最后选择共同产生。

## 原创化距离

至少重构以下全部项目：人名与称谓；职业、身份和社会位置；时间、地点及社会环境；人物关系组合与权力来源；导火索、事件和场景顺序；信息载体、证据与道具；转折方式；结局和主题落点；叙述语言、比喻、意象与对白。

不要使用原作标志性台词、独特场面、专有设定或高度可识别的情节组合。若成稿能够被概括为“原作 B 换了姓名和职业”，则原创化失败，必须重构。
